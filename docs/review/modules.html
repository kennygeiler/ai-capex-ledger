Capex Ledger · module map · 28 Oct 2026

Three modules, each with its own focus and its own definition of done

Ingestion gets documents in exactly as filed. Transformation turns them into cited, dated values. Validation decides what we stand behind. Each module hands the next a fixed contract, so each can be worked on, tested and judged on its own. Ticket statuses are taken from docs/TICKETS.md.

How the modules hand off
