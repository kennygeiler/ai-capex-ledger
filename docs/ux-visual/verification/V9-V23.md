# V9–V23 verification, 2026-11-05

Branch `visual-2` (from main 69a947f). Local copy on port 3630, owner mode, data as of Nov 1, 2026. Measured in Chrome
(Playwright) with `getBoundingClientRect`, computed style and scroll heights at 1600×1000 and 1280×800, before the
fix (69a947f) and after (the commits listed in the branch log), and checked by eye in the app's browser pane.
Screenshots: `docs/ux-visual/verification/shots/before-*.png`, `after-*.png`, `w-*.png` (gitignored, not in git). The
same checks run in `tests.test_layout` (Chrome) and `tests.test_pages_js` (node, the rules as written).

Probes used throughout, as the layout audit counts them less what is not a defect (each stated in the test that uses it):
spills leave out a Bootstrap `.row`'s negative gutter (it sits in its container's padding by design) and Plotly's SVG
text; dead space leaves out SVG layers, `<col>`, a block that is its own text, and what sits in a closed `<details>`
(Chrome boxes it though it is not on screen); spacing leaves out Plotly's modebar.

Flow and V3–V8 checked first: the flow batch had filled Reconcile's rule-finding columns (#6), dropped Release's
by-company card (#2), kept the one open count (#4); V3 had unified every table header (case, size, alignment) and
built sort headers with kit classes. Those criteria are measured below and marked done; nothing was redone.
