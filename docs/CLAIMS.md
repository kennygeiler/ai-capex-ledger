# Claims register

Generated by `uv run python -m ledger.claims` from `claims/claims.yaml` and `claims/findings.jsonl`; do not edit by hand. A row with checks gets its status from the facts; a row without checks starts from its declared status and only gets worse. This file leaves out what depends on the clock or the commit (the EDGAR check's age, the code the hosted copy runs): those read "checked live only" here; the Gaps page and `/api/v1/claims` check them live. How to add a claim or a finding: docs/BUILD.md.
